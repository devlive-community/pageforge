我们很高兴地宣布 PageForge 2025.1.2 正式发布。PageForge 是一款现代化的静态页面生成与部署平台，致力于为用户提供从创建到部署的一站式解决方案。

## 新增功能

- 支持 Mermaid 图表渲染 (#11)
- 支持 Diff 语法展示
- 新增代码块一键复制功能
- 添加返回顶部功能
- 支持文档贡献者列表展示
- 集成 Git 提交信息显示
- 新增 Tooltip 提示功能
- 支持图片加载状态提示
- 支持 Issues 解析与链接 (#4)
- 支持添加统计代码 (#1)

## 界面优化

- 优化页面布局结构
- 拆分页面标题为独立组件
- 优化目录导航体验
- 改进移动端 Git 提交信息显示
- 修复代码块内容过长导致的布局问题
- 修复点击目录后跳转被菜单遮挡问题

## 架构改进

- 拆分国际化为独立模块
- 拆分目录为独立组件
- 拆分 Git 提交信息组件
- 优化 Mermaid 和 Diff 匹配方式
