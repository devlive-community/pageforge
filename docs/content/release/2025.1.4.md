我们发布了 PageForge 2025.1.4 紧急修复版本。此版本主要带来了搜索功能，并修复了一些关键问题。PageForge 是一款现代化的静态页面生成与部署平台，致力于为用户提供从创建到部署的一站式解决方案。

## 新增功能

- 支持全站搜索功能 (#8)
- 搜索结果关键词高亮显示
- 新增团队展示模版

## 界面优化

- 改进目录滚动突出显示和活动状态
- 优化内容与菜单之间的位置计算

## 问题修复

- 修复发布 npm 导致 example 丢失问题 (#38)
- 修复移动端语言选择器报错问题
- 修复移动端触发按钮丢失问题

## 架构改进

- 拆分 JavaScript 文件为独立模块
- 拆分 Logo 和导航组件为独立模块
