title: 2025.1.3
---

我们很高兴地宣布 PageForge 2025.1.3 正式发布。PageForge 是一款现代化的静态页面生成与部署平台，致力于为用户提供从创建到部署的一站式解决方案。

## 新增功能

- 支持页面 SEO 优化 (#7)
- 添加评论功能 (#9)
- 支持字体大小调节 (#13)
- 新增菜单顶部 Banner (#21)
- 支持页面分享功能 (#17)
- 支持站点地图生成 (#5)
- 支持 HTML 压缩 (#19)
- 支持 Dark 模式主题切换
- 支持图标功能与自定义按钮
- 新增多个主页模板

## 界面优化

- 支持包含子项的导航项展开/收缩
- 优化顶部菜单布局
- 添加代码复制 hover 效果
- 支持 diff 代码复制
- 添加图标加载视觉效果
- 添加 git 贡献者头像加载状态和占位符
- 支持自定义页面状态显示
- 修复页面状态提示被容器遮挡问题

## 架构改进

- 拆分主模版部分功能为独立组件
- 拆分查看源码和修改源码为独立组件
- 拆分移动端语言选择器
- 优化导航获取方式
- 支持国际化不存在的文件使用默认语言

## 问题修复

- 修复缩进情况下代码片段无法解析
- 修复站点地图无法新页面打开问题
- 修复未启用国际化时构建站点地图错误
- 修复标题过长导致内容自动换行问题
- 修复嵌套路径导致跳转异常

## 其他更新

- 添加 Google 广告代码支持
- 新增站点地图文档
- 添加压缩配置文档
