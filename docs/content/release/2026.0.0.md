我们很高兴地宣布 PageForge 2026.0.0 正式发布。PageForge 是一款现代化的静态页面生成与部署平台，致力于为用户提供从创建到部署的一站式解决方案。此版本主要增强了阅读体验相关功能。

## 新增功能

- 支持默认 h 标签渲染
- 优化构建速度
- 修复由于未获取 nav + banner 高度导致页面抖动
- 优化修改文件重新编译效率
