title: 2025.1.5
---

我们很高兴地宣布 PageForge 2025.1.5 正式发布。PageForge 是一款现代化的静态页面生成与部署平台，致力于为用户提供从创建到部署的一站式解决方案。此版本带来了多版本文档支持、API 文档模板等重要功能。

## 新增功能

- 支持 API 文档模版 (#20)
- 支持 GitHub 多版本文档发布
- 支持代码块设置标题
- 支持表格标题排列方式配置
- 新增 properties 代码块支持
- 支持 grid 布局扩展
- 支持 note 类型提示信息
- 添加标签内容多匹配模式
- 新增归档命令功能

## 多版本支持优化

- 修复多版本情况下搜索问题
- 修复多版本情况下页面跳转问题
- 修复站点地图多版本问题
- 修复多版本资源目录问题
- 添加搜索结果归属语言显示

## 界面优化

- 优化按钮和图片间距
- 优化 team 模板展示
- 改进提示信息匹配规则
- 支持 grid 子选项内容解析

## 问题修复

- 修复左侧导航菜单子集选中主菜单未标记问题
- 修复目录内容过长自动换行问题
- 修复代码块在其他组件缩进情况下导致宽度拉伸问题
- 修复左侧菜单由于高度问题显示不完整
- 修复移动端链接和导航重叠问题
- 修复 404 页面静态资源问题
- 修复默认语言获取问题
- 修复国际化情况下导致语言错误
- 修复顶部菜单过多时导致其他组件重叠
- 修复解析链接前后内容受影响
- 修复 codespan 解析错误
- 修复表格情况下单元格内容未解析问题

## 架构改进

- 拆分页面数据为独立功能
- 拆分菜单为独立功能
- 拆分国际化为独立功能
- 拆分获取 git 信息功能
- 拆分压缩功能
- 重构标签扩展系统
